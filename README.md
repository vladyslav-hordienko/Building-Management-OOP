# Building Management OOP Model

Java object-oriented model for residential and commercial buildings with reusable address and location objects.

## Features
- Base `Building` class with specialised residential and commercial subclasses.
- Composition between buildings, addresses, and geographic locations.
- Constructor overloading for optional building information.
- Method overriding to provide type-specific information.
- Separate collections for residential and commercial buildings.
- Case-insensitive Eircode search across stored buildings.

## What I practised
Inheritance, composition, encapsulation, polymorphism, method overriding, constructor overloading, Java Collections, object relationships, and simple search logic.
